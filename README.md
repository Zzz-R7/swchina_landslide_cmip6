# Decoding Future Landslide Risk in Southwest China

This repository contains the code and data for the paper:
**Decoding Future Landslide Risk in Southwest China: Spatiotemporal Evolution and Uncertainty Decomposition under CMIP6 Scenarios**

## Requirements
Please install the required Python packages:
`pip install -r requirements.txt`

## Data
Due to size limits, the raw data (HiCPC, DEM, etc.) are not included. 
Please download them following `docs/data_sources.md` and place them in the `data/raw/` folder.

## How to Run
The code is designed to run sequentially.
You can run the whole pipeline via:
`bash run_all.sh`

## Folder Structure
- `src/`: All Python scripts for modeling and analysis.
- `data/`: Placeholder for data (not included).
- `outputs/`: Results, figures, and tables generated by the code.
- `docs/`: Detailed documentation.
